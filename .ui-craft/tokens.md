# Tokens

`DESIGN.md` frontmatter is the complete token record; `.impeccable/design.json` adds focus, motion, breakpoints and standalone component previews. Source is `src/extension/ui/wallet.css`, shared controls in `src/extension/ui/components/`, and isolated extension Tailwind configuration in `vite.extension.config.ts`.

Palette follows the existing Abyss app. Dark background is `oklch(.145 .015 264)`, panel `.205 .02 264`, foreground `.985 .01 264`, primary `.62 .21 264`, action `.55 .21 264`, muted `.708 .02 264`, border `.32 .03 264` and input `.36 .03 264`. Light background is `.93 .025 264`, panel `.99 .006 264`, foreground `.145 .02 264`, primary/action `.485 .18 264`, muted `.4 .02 264`, border/input `.78 .03 264`. The full OKLCH values and semantic warning, error and success roles are in DESIGN.md. Primary drives brand and focus; action supplies white-label contrast in both themes.

Local Inter variable font for UI and headings; local JetBrains Mono for amounts, addresses and word indices. Root/body and ordinary controls (15px); support, navigation and address data (13px); recovery indices and quiet Early alpha badge (12px). Task titles (24px), welcome (30px compact / 32px desktop), balance (36px compact / 40px desktop), payment amount (28px). Financial data uses tabular numerals. Do not inherit the obsolete 8–11px metadata ramp.

Actual Abyss shadcn-based controls use Base UI, CVA and cnfast, adapted for React 18 and Tailwind 3. At the 15px root, standard button/input minimum height is 41.25px; button padding is 9.375px 18.75px and input padding 9.375px 15px. Inputs use 22.5px corners, buttons 9999px; native selects/amount blocks 24px, panels 26px, desktop shell 32px, recovery cells 12px. CSS icon and compact controls have contextual dimensions. Shared controls use a 2px inset focus ring; recovery has one 2px parent outline at -2px offset and no inner ring. State transitions take 150ms; reduced motion removes them. No entrance or general button-press animation.

Spacing uses small even steps with 24/28/32px task separation. Popup is 420px wide with a 600px minimum height, scrollable task and bottom navigation. At 640px the shell is content-sized up to 760px with 560px forms. At 900px the unlocked workspace grows to 960px, navigation moves above content and balance/fund details form two columns. Recovery words keep three columns. Desktop background dots use a 20px grid. Tonal fills, borders and the balance gradient supply depth; panels have no decorative shadows.
